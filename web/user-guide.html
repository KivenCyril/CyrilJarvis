JARVIS User Guide

JARVIS is a Streaming Spec driven personal AI assistant that orchestrates multiple specialist agents, tools, and knowledge sources to accomplish complex tasks. This guide covers everything from getting started to advanced customization.

Quick Start

Get JARVIS running in under 5 minutes:

1. Installation

pip install jarvis-ai # or from source: git clone https://github.com/jarvis/jarvis.git cd jarvis pip install -e .

2. Start the Server

jarvis server start # Server starts at http://127.0.0.1:8000

3. Create Your First Spec

jarvis spec create "Review the auth module for security issues" # Or via API: curl -X POST http://127.0.0.1:8000/specs \ -H "Content-Type: application/json" \ -d '{"intent": "Review the auth module for security issues"}'

4. Chat with an Agent

jarvis agent chat "What are the main security risks in JWT auth?"
Tip
Open the dashboard at http://127.0.0.1:8000 to see the web UI with real-time spec updates, agent activity, and system metrics.

Entity and relationship graph extracted from conversations. Enables connected reasoning.

DAG-based workflow engine for orchestrating multi-step processes with dependencies and approvals.

Streaming Specs

The Streaming Spec is JARVIS's core innovation: a real-time editable task control panel. Unlike static prompts, a Streaming Spec is a living document that you can modify while the AI is working.

Lifecycle

  1. Create: Provide an intent (what you want done)
  2. Plan: JARVIS decomposes the intent into steps with constraints
  3. Edit: You can add/remove constraints, edit steps, or redirect
  4. Execute: Agents work through steps, updating progress in real-time
  5. Complete: All steps done, results available

Key Operations

  • Add Constraint: Add a rule the agents must follow
  • Remove Constraint: Deactivate a constraint
  • Edit Step: Rename or change step description
  • Redirect: Change the spec's intent entirely
  • Pause/Resume: Control execution flow
Real-time Updates
Connect via WebSocket at /ws/specs/{spec_id} to receive real-time updates as the spec executes. The dashboard uses this for live progress display.

CLI Usage

JARVIS provides a comprehensive command-line interface for all operations.

Command Groups

jarvis --help # Show all commands jarvis spec --help # Spec management jarvis agent --help # Agent management jarvis tool --help # Tool management jarvis memory --help # Memory management jarvis knowledge --help # Knowledge graph jarvis skill --help # Skill management jarvis workflow --help # Workflow management jarvis event --help # Event management jarvis notification --help # Notification management jarvis migration --help # Migration tools jarvis server --help # API server jarvis info # System information jarvis diagnose # System diagnostics jarvis benchmark # Performance benchmark

Common Workflows

# Create and run a spec jarvis spec create "Review PR #42 for security issues" jarvis spec run "Refactor the auth module" # Chat with agents jarvis agent chat "What's the best way to handle JWT rotation?" jarvis agent route "debug this python error" # Manage memory jarvis memory add "Project uses FastAPI for the backend" jarvis memory search "backend framework" jarvis memory list # Start the server jarvis server start --port 8000

Migration

JARVIS supports migrating from Hermes and OpenClaw projects. The migration wizard validates your source and transfers agents, workflows, skills, and configuration.

CLI Migration

# Validate before migrating jarvis migration validate hermes /path/to/project # Run migration jarvis migration run hermes /path/to/project # Dry run (preview changes) jarvis migration run openclaw /path/to/project --dry-run

Web Migration

Use the Migration Wizard for a guided step-by-step migration experience.

Important
Always back up your source project before running a migration. The migration process is non-destructive (it copies rather than moves), but having a backup is always recommended.
